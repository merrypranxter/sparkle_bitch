# Bundled fonts

These `.woff2` files and `fonts.css` are generated by
[`scripts/fetch-fonts.cjs`](../scripts/fetch-fonts.cjs), which downloads the
**Latin subset** of a curated set of fonts from Google Fonts.

**Every bundled font is licensed under the SIL Open Font License (OFL) or the
Apache License 2.0**, both of which permit redistribution (bundling) — so the
app can ship them and run fully offline with no external font requests. The full
OFL 1.1 text is in [`OFL.txt`](OFL.txt), and per-family provenance + links to
each font's authoritative license/attribution are in
[`LICENSES.md`](LICENSES.md). Keep those files alongside the `.woff2` files if
you redistribute.

Families: Press Start 2P, Silkscreen, VT323, Pixelify Sans, Orbitron, Michroma,
Audiowide, Zen Dots, Wallpoet, Syncopate, Baloo 2, Fredoka, Bungee, Chewy,
Sniglet, Monoton, Bungee Shade, UnifrakturCook, Pirata One, Permanent Marker,
Rock Salt, Shadows Into Light, Comic Neue.

## Refresh / add more

Edit the `FONTS` table in `scripts/fetch-fonts.cjs`, then:

```bash
node scripts/fetch-fonts.cjs
```

It reuses already-downloaded files and regenerates `fonts.css`. After adding a
family here, also add it to the `GROUPS` table in `js/text.js` so it shows up in
the picker.

## Adding a font that isn't on Google Fonts

You don't need to touch the code: in the app, switch to **Text** mode and click
**＋ Load font file**, then pick any `.ttf` / `.otf` / `.woff` you downloaded
(e.g. from [DaFont](https://www.dafont.com) or
[FontSpace](https://www.fontspace.com)). It loads instantly and appears in the
picker under **Your fonts**, and it's remembered across visits (saved in your
browser's IndexedDB — nothing is uploaded anywhere).
